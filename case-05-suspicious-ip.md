Case 05 — Suspicious IP Investigation

Scenario

A suspicious IP address is identified during log analysis.

Investigation

- Search for other events containing the IP.
- Identify systems contacted.
- Review authentication attempts.
- Check event frequency and timestamps.
- Look for successful activity.
- Compare against available threat information or watchlists.
- Determine whether containment or escalation is required.

Lab Context

During my Microsoft Sentinel practice I created a watchlist called Malicious SSH IPs and used suspicious IP activity as part of detection and investigation exercises.

Progress still ongoing.
